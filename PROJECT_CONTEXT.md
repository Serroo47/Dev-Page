# SERHAT.DEV – Projektstand

## Projekt

Persönliche Developer-Website von Serhat Alptekin.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- App Router
- Keine zusätzliche UI- oder Icon-Library

## Seiten

- `/`
- `/projekte`
- `/ueber-mich`
- `/kontakt`

## Design

- Dark Mode
- Dunkelblauer Hintergrund
- Kühles Blau als Hauptakzent
- Violett nur sehr dezent
- Grid-Hintergrund
- Runde Cards
- Dezente Glows
- Responsive für Desktop und Mobile
